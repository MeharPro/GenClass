# GenClass decision model 0.1.0

- **Architecture:** Ettin encoder 32M (ModernBERT family; 10 layers, hidden 384; global/local attention, 128-token local window), fine-tuned with a block-masked “one question per branch” layout and typed heads (choice softmax, noul sigmoid, score softmax), with per-question temperature calibration.
- **Training data:** synthetic computer-use requests generated by the authors (spoken commands, partial transcripts, side talk, corrections, screens of numbered elements, injected-instruction negatives). No user data. No third-party benchmark data.
- **Base model:** jhu-clsp/ettin-encoder-32m (MIT). **Weights license:** Apache-2.0.
- **Files:** `genclass-fp16.onnx` (67 MB, WebGPU), `genclass-q8.onnx` (57 MB; 8-bit weight-only MatMuls, fp16 embedding table), plus `tokenizer.json`, `calibration.json`, `meta.json`. Inputs: token ids, positions, question/item group ids, marker indices. Outputs: raw choice/score/noul logits; calibration is applied in JavaScript.
- **Parity with PyTorch** (50 harness requests, 503 answers): fp16 503/503 same decision, max |Δ logit| 0.018; q8 502/503, max |Δ logit| 0.37.
- **Intended use:** deciding which browser action a spoken command asks for, with the GenClass harness (policy, safety gates, spoken confirmation for risky actions).
- **Limitations:** English only. Small model: it sometimes misses targets, which leads to clarification prompts. Not suitable for general text classification: zero-shot ad/clickbait classification is near chance, so GenClass uses marker rules for that. Calibrated on synthetic data.
- **Not affiliated** with TypeSafe or Jev.
